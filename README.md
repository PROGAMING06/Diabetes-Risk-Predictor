# 🩺 Diabetes Risk Predictor

## Overview

This project is an interactive healthcare web application designed to collect comprehensive patient metrics and predict a continuous Diabetes Risk Score in real time.

## 🚀 Live Demo

View the live dashboard here:

🔗 https://your-app-url.streamlit.app

## Features

- Interactive Streamlit user interface.
- Comprehensive patient input fields across 36 parameters.
- Real-time Machine Learning prediction.
- CatBoost regression model.

## Technologies Used

- Python.
- Streamlit.
- Pandas.
- CatBoost.
- Pickle.
